# Introduction

**Nation Flag System** lets authorized staff change in-world flag poles to any nation via a ProximityPrompt and searchable ScreenGui — built for visiting-delegate / flag-hall scenarios.

## What you get

- ProximityPrompts on each flag pole
- Group and/or Team authorization (per pole or global)
- ~250 world nations in a searchable picker
- Passport-system asset nations sorted first
- MeshPart `TextureID` swaps on your existing flag meshes
