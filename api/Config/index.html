Config

Global defaults for authorization, flag discovery, and prompts. Override per pole with Attributes (AuthMode, GroupId, MinGroupRank, TeamName).

Properties​

AuthMode​

</>
Config.AuthMode: Types.AuthMode

Default auth mode. "Either" allows group or team.

GroupId​

</>
Config.GroupId: number

Roblox group id. 0 disables the group check.

MinGroupRank​

</>
Config.MinGroupRank: number

Minimum rank required in GroupId.

TeamName​

</>
Config.TeamName: string

Exact Team.Name for team authorization.

FlagFolderPath​

</>
Config.FlagFolderPath: string

Dot path from game to the folder of flag Models (default Workspace.Flags).

CollectionTag​

</>
Config.CollectionTag: string

CollectionService tag for poles outside the flag folder.

PromptActionText​

</>
Config.PromptActionText: string

PromptMaxDistance​

</>
Config.PromptMaxDistance: number

PromptHoldDuration​

</>
Config.PromptHoldDuration: number

DenyMessage​

</>
Config.DenyMessage: string

Toast shown when a player is not authorized.
